## 已验证的完整交互

1. 新建单人故事、选角、新场景自动 3D 投骰并写入气海。
2. 情景法门卡双击推进、人物双击定目标、气骰双击入槽、唯一令牌确认宣言。
3. 法门落果实际令解密值从 0 增至 1。
4. 魏长兴、黑衣脚夫、短兵客、望风探子、暗处弓手依统一行动序列自动推进。
5. 玩家成为目标时自动流程暂停；实际配置并确认一次截击。
6. 玩家响应额度耗尽后不再打开无法提交的第二个窗口，自动进入成招 / 落果。
7. 暗箭落果后沈青气血从 18 降至 16，顶部和人物牌同步反馈。
8. 所有角色行动结束后才进入轮末并重置响应次数。
9. 调息实际支付一枚息引，按内功许可取回两枚息库骰，保留原点数并消耗整次主行动。
10. DM 切换情景 / 战斗表现时沿用第3轮与现有气海，没有重新投骰。
