# R7 交锋系统完整重构记录

日期：2026-07-13
实现目录：`app_design/daliang-trpg-combat`

## 本轮目标

本轮不是单纯换皮，而是把规则书、历次 UI 指令和已有 React 原型收束成同一套可执行交锋桌面。规则与界面共同遵循：选招式 → 选目标 → 配置阴阳槽 → 唯一确认 → 截击 → 成招 → 应招 → 落果 → 资源去向。

设计裁决与详细验收基线见 `app_design/docs/交锋系统重构_R7_设计基线_20260713.md`。

## 已完成

- 将宣言状态统一为 App 持有的单一 `DeclarationDraft`，移除骰子区与外层各自维护槽位造成的双状态。
- 普通招式只保留骰子工作台中的一次“确认宣言并锁气”；底部命令条不再重复确认。
- 中心区改为“抽象交锋台 + 横向行动手牌 + 七区气骰工作台”，不是地图格、棋子移动或网页仪表盘。
- 七个规则区显式落地：气池、气海、锁气、阴槽、阳槽、息库、临气区。
- 气骰支持整枚点击/拖放；阴骰只进阴槽、阳骰只进阳槽、原始骰可进任一槽。
- 正式出手的阴阳双槽门槛在按钮态和规则引擎中同步校验。
- 目标线与交锋台单位统一使用同一百分比坐标系；点击目标可在右栏打开玩家/DM 对应的信息视图。
- 调息、返照统一为行动牌；主持工具只保留来源失效、势调整、手动裁定等主持权限。
- 底部命令条只展示当前阶段的合法推进命令，并随截击、应招、结算、轮末给出对应提示。
- 3D 场景掷骰改为整池事务：动画完成后按骰面 D4→D20、阴→阳→原、点数高→低归位；取消不改状态，确认才写入气海并进入宣言阶段。
- 新开局与清空存档恢复到气池待投状态，不再绕过 3D 场景掷骰。
- 旧存档兼容层补齐气性、势范围、时点与招式必填字段；未知旧时点按正式出手迁移，避免绕过阴阳槽规则或运行时崩溃。
- Debug 面板仅在开发模式且主动开启时显示；玩家公开视图与 DM 隐藏信息继续分离。
- 1366×768 与 1920×1080 桌面断点完成实机检查；手牌与骰子工作台无内部溢出。
