# 《大梁武侠》Windows 桌面覆盖重构实现说明

## 1. 产品与桌面边界

- 正式名称统一为“**大梁武侠**”，剧情名称只属于团包。
- 只正式支持 Windows x64 和中文界面；不提供网页部署、移动端、SEO 或触屏适配。
- React 是游戏渲染技术，Electron 是桌面外壳。正式窗口不显示地址栏或网站导航。
- 默认窗口约 1600×900，支持窗口化、最大化、还原、最小化、关闭和 F11 全屏。
- Electron 启用 `contextIsolation` 与沙箱，关闭页面 Node 权限；React 不直接读写文件系统。
- preload 只暴露受限的窗口、存档和 LAN 能力；拒绝外部导航、新窗口和外部 webview。
- 冷启动始终进入首页，只有用户选择“继续游戏”后才恢复具体存档。
- 存档写入 Windows 应用数据目录，并兼容迁移旧 `localStorage` 数据。

## 2. 已删除的语音范围

本次完全移除玩家语音输入、录音、语音转文字、麦克风按钮、语音设置、语音日志来源和对应测试。不请求麦克风权限，不保存或传输音频，不引入语音模型。背景音乐、环境音和游戏音效仍属于 DM 可配置的场景媒体。

## 3. 三运行态

### SCENE_FREE

- 不强制行动队列。
- 只显示当前场景有合法用法的行为分类，其余收进“查看全部”。
- 玩家依次选择分类或自由叙事、用法、对象、可选办法和公开范围。
- 已选择用法和对象时，补充文字不是必填；纯自由叙事才要求文字。
- 情景保留紧凑气海，需要配气时才展开阴阳槽。

### SCENE_STRUCTURED

- 用于追逐、潜入、争夺和限时救援。
- NPC、队友、敌对人物和动景进入结构化行动序列。
- 危机、解密、许可、关系和资源事实与事件触发相连，不是孤立进度条。

### COMBAT

- 情景转入战斗只改变场景表现和合法动作。
- 沿用气海、息库、临气、状态、对象和轨道，不重新投骰。
- 玩家桌面只保留顶部顺序、中央距离战场、七区气域、横向手牌和收起的抽屉题签。

## 4. 权威交锋流程

```text
战斗先后
  → 宣言
  → 锁气
  → 截击
  → 成招
  → 基础效果
  → 槽值触发
  → 应招
  → 落果
  → 资源去向
  → 下一角色
  → 全员完成后轮末
```

- 主动响应额度和自保应招额度分开记录。
- 截击与应招不打开独立大弹窗，而在原手牌和气骰区处理。
- 玩家成为目标或拥有护人机会时，自动角色流程暂停。
- 无合法招式时按移动、调整势、调息、返照、放弃出手依次兜底；仍无操作时安全推进并记录原因。
- 所有动效只表现已经确定的权威结果，不参与计算。

## 5. 调息与返照

### 调息

- 支付一枚息引。
- 从息库取回规则允许的常规骰并保持原点数。
- 消耗正式出手。
- 不治疗、不清状态、不改变势。

### 返照

- 只在气海断气且仍有行动机会时可用。
- 每轮一次。
- 取最低阶本命骰重投。
- 不消耗正式出手。

移动、调整势、援手和放弃出手均为真实基础行动卡，不是说明文字。

## 6. 骰子与动画

- 唯一七区：气池、气海、临气、锁气、阴槽、阳槽和息库。
- 新场景整体投骰一次；后续加入且没有本场景骰面的角色只补投自己。
- 权威随机结果先生成，Three.js / 2D 只负责表现。
- Three.js 渲染器、几何体、材质和环境资源复用；异常时自动回退 2D。
- 常规骰视觉尺寸约 26—36 像素，高阶骰不超过 42 像素。
- 动态落点网格和结束整理防止堆叠、飞出与点数遮挡。
- 标准动画约 0.8—1 秒，快速模式约 0.3 秒；空格跳过表现但不跳过规则。
- `MotionController` 统一管理 0.5×、1×、1.5× 和 2× 动画速度。

## 7. 玩家与 DM 的权限边界

- 玩家只控制自己的角色，看不到隐藏 NPC、敌方完整骰子、隐藏目标和 DM 备注。
- 规则型自动 DM 在单机和断网时也能完整运行，不依赖外部 AI。
- 真人 DM 运行台拥有场景树、共享画面监看、玩家意图、裁定队列、广播、手动接管和隐藏牌匣。
- DM 创作工作台与运行台分离，提供资源库、剧情图 / 场景画布、属性检查器、验证、预览和模拟。
- DM 自由文本不会直接修改权威状态；只有通过结构校验的效果、触发器和裁定事务可以落地。
- 所有 DM 手动覆盖、公开隐藏内容和广播均进入日志。

## 8. LAN 与存档

- DM 作为房主启动内嵌本地服务。
- 协议支持房间码、席位、准备、角色冲突、版本握手、权威快照、断线恢复和事务去重。
- 玩家不能提交 DM 专属字段；私密文字只发送 DM。
- LAN 不传输音频。
- 服务停止时会先终止所有活动客户端，避免测试和退出流程悬挂。
