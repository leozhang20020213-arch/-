## 调息与返照

2026-06-20 玩家规则书正文、表格和开发者稿在“是否重投、是否消耗正式出手”上存在冲突。应用以 2026-07-15 任务书的专项冻结为最高优先级。

| 编号 | 最终冻结口径 | 说明 |
|---|---|---|
| RF-020 | 调息消耗一次正式行动机会 | 它是特殊出手便行 |
| RF-021 | 调息必须支付一枚气海或临气骰作为息引 | 防止无成本无限回气 |
| RF-022 | 默认从息库取回一枚合法常规骰；条目可明确增加 | 临气不走普通调息 |
| RF-023 | 调息取回的骰子保留当前点数，不重投 | 与任务书测试矩阵一致 |
| RF-024 | 调息不治疗、不清状态、不改势、不加护体 | 只处理气骰调度 |
| RF-025 | 返照仅在气海没有可用常规骰且角色仍有行动机会时可用 | 断气保底 |
| RF-026 | 返照每轮一次，取回息库最低阶合法本命骰并重投入气海 | 与调息的“不重投”明确区分 |
| RF-027 | 返照不消耗正式出手，但不能产生额外出手机会 | 特殊随手便行；返照后仍只能使用原有行动机会 |
| RF-028 | 调息/返照资格、次数和资源变化必须进入事务日志 | 防重复触发与网络重放 |
